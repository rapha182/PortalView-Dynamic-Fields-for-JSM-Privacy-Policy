Overview PortalView is an Atlassian Forge app designed for Jira Service Management. It runs entirely on Atlassian’s cloud infrastructure (“Runs on Atlassian”) and does not use external servers. Data Access and Storage The app accesses Jira and Jira Service Management data, including user-provided content such as issue fields, comments, requester information, and SLA data, solely to display information already visible to authorized users. PortalView does not store or transmit personal data outside Atlassian systems. Configuration data (such as Project ID, Request Type, selected fields, and SLA ID) is stored using Atlassian Forge Storage and is scoped to the specific Jira instance. Data Sharing PortalView does not share or sell data to third parties. All data access and processing occurs within the Atlassian ecosystem. Data Retention and Deletion Configuration data is retained only while the app is installed. When the app is uninstalled, all stored configuration data is automatically deleted from Atlassian Forge Storage. User Rights PortalView respects applicable data protection regulations, including GDPR and LGPD. Requests related to configuration data can be made by contacting the developer. Access to Jira data itself is governed by Atlassian’s permission and security model. Responsibility The developer is responsible for the application logic and configuration data handled by PortalView.
