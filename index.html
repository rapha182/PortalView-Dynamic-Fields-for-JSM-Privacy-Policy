PortalView – Privacy Policy 1. Overview PortalView is an Atlassian Forge app designed for Jira Service Management. It operates as a "Runs on Atlassian" app, meaning it executes entirely within Atlassian’s cloud infrastructure and uses no external servers. 2. Data Collection and Storage Personal Data: We do not collect or store personal data (like names or emails) outside of Atlassian's systems. The app only accesses information provided by Atlassian APIs during runtime to perform its functions. Configuration Data: We store minimal configuration settings (Project ID, Request Type, selected fields, SLA ID) using Atlassian Forge Storage. This data is bound to your specific Jira instance. 3. Data Sharing No data is shared with or sold to third parties. All processing remains within the Atlassian ecosystem. 4. Data Retention and Deletion Configuration data is retained as long as the app is installed. Once the app is uninstalled, all stored configuration data is automatically deleted from Forge Storage. 5. User Rights As the developer of PortalView, we respect your rights under GDPR and LGPD. Users can request access to or deletion of any configuration data by contacting us. Note that most data access is governed by your Jira permission model. 6.
